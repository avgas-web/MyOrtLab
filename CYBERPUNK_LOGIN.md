# Cyberpunk Login Screen - Документация

## Описание изменений

Стартовый экран входа в систему MyOrtLab/GnatOne был полностью переработан в стиле киберпанк с использованием реального КТ-изображения черепа.

## Реализованные эффекты

### 1. Фоновое изображение
- **Источник:** https://vsemrt.ru/images/kt-kostey-licevogo-cherepa.jpg
- **Обработка:** 
  - Черно-белый фильтр (grayscale 100%)
  - Уменьшенная яркость (brightness 0.4)
  - Увеличенный контраст (contrast 1.3)
  - Прозрачность 70%
- **Позиционирование:** На весь экран (cover), центрировано

### 2. Синий отлив
- Градиентный оверлей с цветами cyan-teal
- Режим наложения: overlay
- Прозрачность: 10-15%
- Создает эффект цифрового свечения

### 3. Белый шум
- SVG-текстура с фрактальным шумом
- Анимация перемещения (0.5s, 10 шагов)
- Прозрачность: 8%
- Имитирует помехи старого монитора

### 4. Сканирующая линия
- Горизонтальная линия cyan цвета
- Анимация движения сверху вниз (8s)
- Эффект свечения (box-shadow)
- Имитирует сканирование КТ-аппарата

### 5. Мерцание текста
- Анимация flicker для заголовка "MyOrtLab"
- Нерегулярное изменение прозрачности
- Создает эффект нестабильного изображения

### 6. Форма входа
- Полупрозрачный темный фон (bg-slate-900/90)
- Backdrop blur для размытия фона
- Неоновая граница cyan цвета
- Моноширинный шрифт для текста
- Градиентная кнопка входа

## Технические детали

### CSS анимации

```css
/* Шум */
@keyframes noise {
  0%, 100% { background-position: 0 0; }
  10% { background-position: -5% -10%; }
  /* ... 10 шагов */
}

/* Сканирующая линия */
@keyframes scanLine {
  0% { transform: translateY(-100%); }
  100% { transform: translateY(100vh); }
}

/* Мерцание */
@keyframes flicker {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.8; }
  52% { opacity: 1; }

}
```

## Демонстрация

При загрузке страницы пользователь видит:
1. Черно-белое КТ-изображение черепа на весь экран
2. Синий полупрозрачный отлив поверх изображения
3. Движущуюся сканирующую линию
4. Мерцающий белый шум
5. Полупрозрачную форму входа по центру
6. Мерцающий заголовок "MyOrtLab"

Все эффекты работают вместе, создавая атмосферу высокотехнологичной медицинской лаборатории в стиле киберпанк.
