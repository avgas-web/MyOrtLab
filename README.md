## 🎯 Основные модули

### 1. Калькулятор себестоимости (только для админа ЛК)
- 80+ продуктов в 12 категориях
- Все поля пустые для заполнения администратором
- Встроенные формулы расчёта себестоимости, маржинальности, рентабельности
- Экспорт/импорт в JSON и Excel
- Индивидуальные ставки для продуктов

### 2. Генератор договоров
- Генерация двух DOCX-файлов (Гнатон + Симбиоз)
- 70+ позиций в прейскуранте
- Автоматическое скачивание
- Доступ: админ ЛК, админ ЗТЛ, менеджер сопровождения

### 3. Управление заказами
- Конвейерная обработка с 16 статусами
- Автоматическое определение типа заказа
- Назначение техников и контроль выполнения
- Встроенный мессенджер
- Управление файлами и комментариями

### 4. Дополнительно
- 10 типов ролей с разграничением прав
- Мультиязычность (RU/EN/KZ)
- Темная/светлая тема
- Киберпанк дизайн стартового экрана
- Адаптивный дизайн
- Печать заказ-нарядов
- Формирование счетов

## 🌐 Деплой на GitHub Pages

### Настройка

1. Включите GitHub Pages: **Settings → Pages → Source: GitHub Actions**
2. Проверьте permissions: **Settings → Actions → General → Read and write permissions**
3. Убедитесь, что репозиторий публичный
4. Запустите workflow: **Actions → Deploy to GitHub Pages → Run workflow**

Сайт будет доступен по адресу: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

### Подробная инструкция

См. [DEPLOYMENT.md](DEPLOYMENT.md)
