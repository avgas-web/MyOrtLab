# MyOrtLab / GnatOne - Личный кабинет зуботехнической лаборатории

## 📋 Описание

Полнофункциональное веб-приложение для управления заказами зуботехнической лаборатории с поддержкой многопользовательской работы, разграничением ролей, конвейерной обработкой заказов и CRM-функциями.

## ✨ Основные возможности

### 🔄 Три типа заказов

1. **Обычные заказы** (ЗТЛ, Гнатология)
   - Полный маршрут: Проверка файлов → Принятие решения → (Гипс → Сканирование) → Ценообразование → Оплата → CAD/CAM → Согласование → Производство → Доставка → Сдача → Закрытие
   - Маршрут "Только CAD/CAM": до согласования CAD/CAM
   - Маршрут "Только физическое": без CAD/CAM, только физическое производство

2. **Ремонтные работы**
   - Отдельная ветка: Заявка → Согласование → Оплата → Ремонт → Отправка → Закрытие
   - Без проверки файлов, гипса и сканирования

3. **Гарантийные работы**
   - Отдельная ветка: Заявка → Согласование → Ремонт/замена → Отправка → Закрытие
   - Без оплаты

### 👥 Роли пользователей

- **Администратор ЛК** - полный доступ ко всем функциям
- **Администратор ЗТЛ** - управление заказами, назначение техников, утверждение стоимости
- **Менеджер по качеству** - проверка файлов
- **Доктор** - создание заказов, согласование работ
- **Управляющий клиники** - просмотр заказов своей клиники
- **Маркетолог** - публикация новостей
- **Технические роли** (гипсовщик, сканер, CAD/CAM, керамист, техник физ. производства, 3D-печать) - выполнение работ
- **Менеджер сопровождения** - управление заказами назначенных докторов

## 📖 Использование

### Создание заказа

1. Войдите под ролью доктора или администратора
2. Перейдите в раздел "Новый заказ"
3. Выберите тип заказа (Полный, Только CAD/CAM, Только физическое, Ремонт, Гарантия)
4. Для обычных заказов:
   - Выберите пациента
   - Добавьте позиции из каталога услуг
   - Укажите наличие физических слепков
   - Заполните план лечения
   - Установите срок сдачи
5. Для ремонта/гарантии:
   - Опишите проблему
   - Для гарантии укажите номер исходного заказа
6. Нажмите "Отправить заказ в работу"

### Управление заказом

1. Перейдите в раздел "Заказы"
2. Найдите нужный заказ (поиск, фильтры)
3. Откройте карточку заказа
4. В зависимости от статуса и роли доступны действия:
   - Принять/вернуть файлы
   - Назначить техников
   - Подтвердить оплату
   - Отметить выполнение работ
   - Согласовать работы
   - Отправить на доставку
   - Закрыть заказ

### Работа с материалами

1. Перейдите в раздел "Материалы"
2. Вкладка "Номенклатура" - просмотр и редактирование материалов
3. Вкладка "Приход" - добавление новых поступлений
4. Вкладка "Отчёт за месяц" - анализ расхода материалов

### GMAI (AI-отчёты)

1. Перейдите в раздел "GnatoneMirror"
2. Выберите пациента
3. Нажмите "Сформировать AI-отчёт"
4. Система отправит запрос к webhook (настраивается администратором)
5. Просмотрите сгенерированный отчёт

## 📐 Архитектура

### Структура данных

```typescript
AppData {
  users: User[]              // Пользователи
  patients: Patient[]        // Пациенты
  catalog: Service[]         // Каталог услуг
  workTypes: WorkType[]      // Виды работ
  materials: Material[]      // Материалы
  stockIn: StockIn[]         // Приход материалов
  materialUsage: MaterialUsage[]  // Расход материалов
  orders: Order[]            // Заказы
  news: NewsItem[]           // Новости
  mirrorReports: AIReport[]  // AI-отчёты
  rolesMeta: RoleMeta        // Метаданные ролей
  settings: Settings         // Настройки (язык, цены GMAI)
}
```

### Статусы заказов

**Обычные заказы:**
- quality → returned → quality (возврат)
- quality → accept → (gypsum → scanning) → admin_pricing → payment → cadcam → approve → (correction) → production → delivery → handover → (correction) → closing → done

**Ремонт:**
- repair_create → repair_approve → (отклонение → done) → payment → production → delivery → closing → done

**Гарантия:**
- guarantee_create → guarantee_approve → (отклонение → done) → production → delivery → done

## 🔧 Настройка webhook для GMAI

Администратор ЛК может настроить URL webhook для интеграции с внешним AI-сервисом:

1. Перейдите в раздел "GnatoneMirror"
2. В блоке "Настройки webhook" укажите URL
3. При генерации AI-отчёта система отправит POST-запрос с данными пациента

**Пример payload:**
```json
{
  "patientId": "p1",
  "patientName": "Иванов Иван Иванович",
  "orders": [...],
  "files": [...],
  "history": "..."
}
```
