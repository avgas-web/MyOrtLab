# MyOrtLab - WordPress Plugin

Полнофункциональная система управления зуботехнической лабораторией для WordPress.

## 📋 Описание

MyOrtLab - это комплексное решение для управления зуботехнической лабораторией, реализованное как плагин WordPress. Плагин обеспечивает полный жизненный цикл заказов от создания до сдачи, включая:

- Управление заказами с конвейерной обработкой
- Управление пациентами и докторами
- Каталог услуг с автоматическим определением маршрута
- Управление материалами и их расходом
- Назначение техников и контроль выполнения работ
- CRM-функции и аналитика
- Многопользовательская работа с разграничением ролей

## 📦 Установка

### Требования
- WordPress 5.8 или выше
- PHP 7.4 или выше
- MySQL 5.7 или выше

### Инструкция по установке

1. **Скачайте плагин**
   ```bash
   git clone https://github.com/your-repo/myortlab-wordpress.git
   ```

2. **Загрузите в WordPress**
   - Скопируйте папку `myortlab-wordpress` в директорию `wp-content/plugins/`
   - Или создайте ZIP-архив и загрузите через админку WordPress

3. **Активируйте плагин**
   - Перейдите в админку WordPress → Плагины
   - Найдите "MyOrtLab - Dental Lab Management System"
   - Нажмите "Активировать"

4. **Проверьте базу данных**
   При активации плагин автоматически создаст необходимые таблицы:
   - `wp_myortlab_users` - пользователи системы
   - `wp_myortlab_patients` - пациенты
   - `wp_myortlab_catalog` - каталог услуг
   - `wp_myortlab_work_types` - виды работ
   - `wp_myortlab_materials` - материалы
   - `wp_myortlab_orders` - заказы
   - `wp_myortlab_positions` - позиции заказов
   - `wp_myortlab_work_items` - работы в позициях
   - `wp_myortlab_files` - файлы заказов
   - `wp_myortlab_comments` - комментарии
   - `wp_myortlab_history` - история изменений
   - `wp_myortlab_stock_in` - приход материалов
   - `wp_myortlab_material_usage` - расход материалов
   - `wp_myortlab_news` - новости
   - `wp_myortlab_settings` - настройки

5. **Добавьте демо-данные**
   При первой активации плагин автоматически добавит демо-данные:
   - 5 пользователей (admin, ztl, doctor, tech1, quality)
   - 3 услуги в каталоге
   - 3 вида работ
   - 2 материала

## 🔧 Использование

### Шорткоды

Плагин предоставляет шорткоды для встраивания функционала на страницы:

#### Дашборд
```
[myortlab_dashboard]
```
Отображает главную страницу с KPI и канбан-доской.

#### Список заказов
```
[myortlab_orders]
```
Отображает таблицу всех заказов с фильтрами.

#### Каталог услуг
```
[myortlab_catalog]
```
Отображает каталог услуг с поиском.

### Админ-панель

После активации в админке WordPress появится раздел "MyOrtLab" с подразделами:

- **Заказы** - управление заказами
- **Пациенты** - управление пациентами
- **Каталог** - управление каталогом услуг
- **Виды работ** - управление видами работ
- **Материалы** - управление материалами
- **Настройки** - настройки плагина

### Роли пользователей

Плагин создает следующие роли WordPress:

- **myortlab_admin** - Администратор ЛК (полный доступ)
- **myortlab_admin_ztl** - Администратор ЗТЛ (управление заказами)
- **myortlab_doctor** - Доктор (создание заказов)
- **myortlab_technician** - Техник (выполнение работ)
- **myortlab_quality** - Менеджер по качеству (проверка файлов)

### Демо-аккаунты

После установки доступны следующие демо-аккаунты:

| Логин | Роль | Описание |
|-------|------|----------|
| admin | Администратор ЛК | Полный доступ |
| ztl | Администратор ЗТЛ | Управление заказами |
| doctor | Доктор | Создание заказов |
| tech1 | Техник | Выполнение работ |
| quality | Менеджер качества | Проверка файлов |

## 🎨 Кастомизация

### Стили

Плагин использует собственные CSS файлы:
- `assets/css/admin.css` - стили для админки
- `assets/css/frontend.css` - стили для фронтенда

Вы можете переопределить стили, добавив свой CSS в тему:

```css
.myortlab-kpi-value {
    color: #your-color !important;
}
```

### Шаблоны

Шаблоны находятся в директории `templates/`:
- `dashboard.php` - дашборд
- `orders.php` - список заказов
- `catalog.php` - каталог услуг

Вы можете скопировать их в свою тему для кастомизации:
```
your-theme/myortlab/dashboard.php
your-theme/myortlab/orders.php
your-theme/myortlab/catalog.php
```

## 🔌 AJAX API

Плагин предоставляет AJAX API для интеграции:

### Получить заказы
```javascript
jQuery.ajax({
    url: ajaxurl,
    type: 'POST',
    data: {
        action: 'myortlab_get_orders',
        nonce: myortlab_ajax.nonce
    },
    success: function(response) {
        console.log(response.data);
    }
});
```

### Создать заказ
```javascript
jQuery.ajax({
    url: ajaxurl,
    type: 'POST',
    data: {
        action: 'myortlab_create_order',
        nonce: myortlab_ajax.nonce,
        patient_id: 1,
        doctor_id: 2,
        clinic: 'Клиника 1',
        category: 'ЗТЛ',
        type: 'full',
        due_date: '2026-02-01',
        due_time: '10:00',
        term_days: 14
    },
    success: function(response) {
        console.log(response.data);
    }
});
```

### Обновить статус заказа
```javascript
jQuery.ajax({
    url: ajaxurl,
    type: 'POST',
    data: {
        action: 'myortlab_update_order_status',
        nonce: myortlab_ajax.nonce,
        order_id: 1,
        status: 'accept',
        reason: ''
    },
    success: function(response) {
        console.log(response.data);
    }
});
```

### Добавление новых функций

1. **Добавить AJAX обработчик**
   В файле `myortlab.php` в методе `register_ajax_handlers()`:
   ```php
   add_action('wp_ajax_myortlab_new_function', array($this, 'ajax_new_function'));
   ```

2. **Реализовать метод**
   ```php
   public function ajax_new_function() {
       check_ajax_referer('myortlab_nonce', 'nonce');
       // Ваш код
       wp_send_json_success($result);
   }
   ```

3. **Вызвать из JavaScript**
   ```javascript
   jQuery.ajax({
       url: myortlab_ajax.ajax_url,
       type: 'POST',
       data: {
           action: 'myortlab_new_function',
           nonce: myortlab_ajax.nonce,
           // параметры
       }
   });
   ```

## 🐛 Известные ограничения

Данная версия плагина имеет следующие ограничения:

1. **Нет реальной системы уведомлений** - настройки сохраняются, но уведомления не отправляются
2. **Нет интеграции с AI-сервисом** - GMAI не реализован
3. **Файлы хранятся в базе данных** - для больших файлов рекомендуется использовать медиа-библиотеку WordPress
4. **Нет мультиязычности интерфейса** - только русский язык
