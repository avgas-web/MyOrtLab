# Темная тема и выбор пути выполнения услуг

## Обзор изменений

В данной версии реализованы два ключевых улучшения:

1. **Полноценная темная тема** - изменен весь дизайн сайта, а не только текст
2. **Выбор пути выполнения для услуг** - администратор может указать путь для каждой услуги в каталоге

## 2. Выбор пути выполнения для услуг

### Что изменилось

Теперь при создании или редактировании услуги в каталоге администратор может указать путь выполнения:

- **Автоматически** - система сама определяет путь на основе категории услуги
- **Полный (CAD + Физика)** - услуга требует и CAD/CAM моделирования, и физического производства
- **Только CAD/CAM** - услуга требует только виртуального моделирования
- **Только физическое** - услуга требует только физического производства

### Как это работает

#### При создании заказа

Когда доктор создает заказ и добавляет услуги:

1. Система проверяет поле `route` для каждой услуги
2. Если хотя бы одна услуга имеет явный путь (не "auto"), используется он
3. Если есть разные явные пути, используется "full" (полный маршрут)
4. Если все услуги имеют "auto", система определяет путь автоматически на основе категорий

#### Примеры

**Пример 1: Явный путь**
```
Услуга: "Коронка металлокерамическая"
Путь: "Полный (CAD + Физика)"

При добавлении в заказ система установит тип заказа: full
```

**Пример 2: Автоматическое определение**
```
Услуга: "Винир керамический"
Путь: "Автоматически"
Категория: "Ортопедия"

Система автоматически определит: cadcam_only
```

**Пример 3: Смешанные пути**
```
Услуга 1: "Коронка" - Путь: "Только CAD/CAM"
Услуга 2: "Протез Ао4/6" - Путь: "Полный"

Система установит: full (полный маршрут)
```

#### Обновление функции determineOrderType

Функция теперь учитывает поле `route`:

```typescript
export function determineOrderType(positions: { 
  svcId: string | null; 
  cat: string; 
  route?: 'auto' | 'full' | 'cadcam_only' | 'phys_only' 
}[]): 'full' | 'cadcam_only' | 'phys_only' {
  
  // Если есть услуги с явным указанием пути, используем их
  const explicitRoutes = positions.filter(p => p.route && p.route !== 'auto');
  if (explicitRoutes.length > 0) {
    const routes = new Set(explicitRoutes.map(p => p.route));
    if (routes.size > 1) return 'full';
    return explicitRoutes[0].route as 'full' | 'cadcam_only' | 'phys_only';
  }
  
  // Автоматическое определение по категориям
  // ... (остальной код)
}
```

## Примеры использования

### Сценарий 1: Явное указание пути

Администратор создает услугу "Коронка на имплант":
1. Открывает каталог услуг
2. Нажимает "+ Добавить новую услугу"
3. Заполняет поля:
   - Категория: ЗТЛ
   - Подкатегория: Имплантология
   - Название: Коронка на имплант
   - Срок: 14 дней
   - Стоимость: 25000 ₽
   - **Путь выполнения: Полный (CAD + Физика)**
4. Нажимает "Сохранить"

Теперь при добавлении этой услуги в заказ система автоматически установит тип заказа: `full`

### Сценарий 2: Автоматическое определение

Администратор создает услугу "Винир керамический":
1. Открывает каталог услуг
2. Нажимает "+ Добавить новую услугу"
3. Заполняет поля:
   - Категория: ЗТЛ
   - Подкатегория: Ортопедия
   - Название: Винир керамический
   - Срок: 10 дней
   - Стоимость: 20000 ₽
   - **Путь выполнения: Автоматически** (по умолчанию)
4. Нажимает "Сохранить"

При добавлении в заказ система автоматически определит путь на основе категории "Ортопедия" → `cadcam_only`

### Сценарий 3: Изменение пути существующей услуги

Администратор хочет изменить путь для услуги "Протез Ао4/6":
1. Открывает каталог услуг
2. Находит услугу "Протез Ао4/6"
3. Нажимает "Редактировать"
4. Изменяет поле "Путь выполнения" с "Автоматически" на "Полный (CAD + Физика)"
5. Нажимает "Сохранить"

Теперь все новые заказы с этой услугой будут использовать полный маршрут.
