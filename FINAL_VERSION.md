## 📋 О проекте

MyOrtLab/GnatOne - полнофункциональное веб-приложение для управления зуботехнической лабораторией с конвейерной обработкой заказов, CRM-функциями, калькулятором себестоимости и генератором договоров.

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

### Деплой на GitHub Pages

1. Включите GitHub Pages: Settings → Pages → Source: **GitHub Actions**
2. Проверьте permissions: Settings → Actions → General → **Read and write permissions**
3. Убедитесь, что репозиторий публичный
4. Запустите workflow: Actions → Deploy to GitHub Pages → Run workflow

Сайт будет доступен по адресу: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

## 🐛 Известные ограничения

### Демо-режим
- Данные хранятся в localStorage (не в базе данных)
- Нет серверной части
- Нет реальной системы уведомлений
- Нет интеграции с AI-сервисом GMAI

### Производительность
- Размер бандла > 500 kB (можно оптимизировать code-splitting)
- localStorage имеет лимит ~5-10 MB

### Безопасность
- Пароли хранятся в открытом виде (демо-режим)
- Нет JWT авторизации
- Нет CSRF защиты
