## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка

```bash
# Клонирование репозитория
git clone https://github.com/your-repo/myortlab.git
cd myortlab

# Установка зависимостей
npm install
```

### 2. Разработка

```bash
# Запуск в режиме разработки
npm run dev

# Открыть http://localhost:5173
```

### 3. Сборка

```bash
# Сборка для продакшена
npm run build

# Предпросмотр
npm run preview
```

### 4. Деплой

1. Включите GitHub Pages: **Settings → Pages → Source: GitHub Actions**
2. Запустите workflow: **Actions → Deploy to GitHub Pages → Run workflow**
3. Сайт будет доступен: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

## 🐛 ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

### Демо-режим
- Данные хранятся в localStorage (не в базе данных)
- Нет серверной части
- Нет реальной системы уведомлений
- Нет интеграции с AI-сервисом GMAI

### Производительность
- Размер бандла > 500 kB (можно оптимизировать code-splitting)
- localStorage имеет лимит ~5-10 MB

### Безопасность
- Пароли хранятся в открытом виде (демо-режим)
- Нет JWT авторизации
- Нет CSRF защиты
