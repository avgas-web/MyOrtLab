# Интеграция модулей Калькулятор прайса и Генератор договоров

## ✅ Что было реализовано

В проект успешно интегрированы два новых модуля:

### 1. Калькулятор прайса (PriceCalculator)
**Доступ**: Только для Администратора ЛК

**Функционал**:
- Управление категориями и продуктами (древовидная структура)
- Расчёт себестоимости, маржинальности и рентабельности
- Глобальные параметры (НДФЛ, страховые взносы, маркетинг, постоянные расходы, целевая рентабельность)
- Индивидуальные ставки для отдельных продуктов
- Строки затрат трёх типов:
  - `material_percent` - процент от цены
  - `material` - материал с количеством и ценой
  - `work` - работа с количеством и ставкой
- Автоматический расчёт всех показателей:
  - Итого материалы
  - Маркетинг
  - ЗП техника
  - ЗП с НДФЛ
  - ЗП со взносами
  - Итого переменные расходы
  - Маржинальность и маржинальность %
  - Постоянные расходы
  - Чистая прибыль
  - Рентабельность %
  - Целевая цена
  - Δ целевой цены
- Редактирование "на лету" (все числовые поля редактируемы)
- Сворачивание/разворачивание категорий
- Экспорт/импорт данных:
  - JSON (полное состояние)
  - Excel (полная таблица со всеми расчётами)
  - Excel (чистый прайс)

### 2. Генератор договоров (ContractGenerator)
**Доступ**: Администратор ЛК, Администратор ЗТЛ, Менеджер сопровождения

**Функционал**:
- Форма ввода данных заказчика (все реквизиты)
- Генерация двух DOCX-файлов одновременно:
  - Договор с ООО "Гнатон" (11 разделов + прайс + подписи)
  - Договор с ООО "Симбиоз" (11 разделов + прейскурант 70+ позиций + приложения + подписи)
- Валидация всех обязательных полей
- Автоматическое скачивание файлов с правильными именами
- Реквизиты исполнителей зашиты в коде
- Прайс-листы для обоих договоров

## 🚀 Использование

### Калькулятор прайса

1. **Доступ**: Главное меню → "📊 Калькулятор прайса"
2. **Создание категории**: Нажмите "+ Категория"
3. **Добавление продукта**: В категории нажмите "+ Продукт"
4. **Настройка продукта**:
   - Укажите название и базовую цену
   - Добавьте строки затрат (материалы, работы)
   - При необходимости включите "Индивидуальные ставки"
5. **Глобальные параметры**: Измените в верхней части страницы
6. **Экспорт данных**:
   - JSON: кнопка "📥 JSON"
   - Excel (полный): кнопка "📊 Excel"
   - Excel (прайс): кнопка "📋 Прайс"

### Генератор договоров

1. **Доступ**: Главное меню → "📄 Генератор договоров"
2. **Заполнение формы**:
   - Номера договоров (Гнатон и Симбиоз)
   - Реквизиты заказчика (наименование, адрес, ИНН, КПП, ОГРН)
   - Банковские реквизиты
   - Должность и ФИО подписанта (в двух падежах)
   - Дата и город
3. **Генерация**: Нажмите "📄 Сгенерировать 2 DOCX"
4. **Результат**: Автоматически скачиваются два файла:
   - `Договор_Гнатон_[номер]_[заказчик].docx`
   - `Договор_Симбиоз_[номер]_[заказчик].docx`

## 📊 Расчётные показатели (Калькулятор)

Для каждого продукта рассчитываются:

1. **Итого материалы** - сумма всех строк типа `material` и `material_percent`
2. **Маркетинг** - цена × маркетинг%
3. **ЗП техника** - сумма всех строк типа `work`
4. **ЗП с НДФЛ** - ЗП техника / (1 – НДФЛ%)
5. **ЗП со взносами** - ЗП с НДФЛ + ЗП с НДФЛ × страховые%
6. **Итого переменные расходы** - материалы + маркетинг + ЗП со взносами
7. **Маржинальность** - цена – переменные расходы
8. **Маржинальность %** - маржинальность / цена × 100%
9. **Постоянные расходы** - цена × постоянные%
10. **Чистая прибыль** - цена – переменные – постоянные
11. **Рентабельность %** - чистая прибыль / цена × 100%
12. **Целевая цена** - (переменные + постоянные) / (1 – целевая рентабельность%)
13. **Δ целевой цены** - цена – целевая цена

## 📄 Структура договоров

### Договор с ООО "Гнатон":
- Шапка с номером и датой
- Преамбула (стороны договора)
- 11 разделов:
  1. Предмет договора
  2. Права и обязанности сторон
  3. Стоимость услуг и порядок расчётов
  4. Сроки оказания услуг
  5. Порядок сдачи-приёмки
  6. Ответственность сторон
  7. Гарантии
  8. Конфиденциальность
  9. Разрешение споров
  10. Срок действия договора
  11. Заключительные положения
- Таблица реквизитов (Исполнитель и Заказчик)
- Таблица подписей
- Приложение №1: Прайс-лист (8 позиций)
- Таблица подписей в приложении

### Договор с ООО "Симбиоз":
- Шапка с номером и датой
- Преамбула (стороны договора)
- 11 разделов (аналогично Гнатон)
- Пункт 12: Прейскурант (70+ позиций)
- Таблица реквизитов
- Таблица подписей
- Приложение №1: Заказ-наряд (форма)
- Приложение №2: Регламент сотрудничества
- Таблица подписей

## 🛠️ Технические детали

### Зависимости:
```json
{
  "docx": "^8.2.2",
  "file-saver": "^2.0.5",
  "xlsx": "^0.18.5",
  "@types/file-saver": "^2.0.7"
}
```

### Размер бандла:
- До интеграции: ~311 kB
- После интеграции: ~1007 kB
- Увеличение: ~696 kB (библиотеки docx и xlsx)

### Оптимизация (рекомендации):
Для уменьшения размера бандла можно:
1. Использовать dynamic import() для ленивой загрузки компонентов
2. Настроить manualChunks в vite.config.js
3. Загружать библиотеки docx и xlsx только при необходимости

### Пример ленивой загрузки:
```typescript
const PriceCalculator = lazy(() => import('./components/PriceCalculator'));
const ContractGenerator = lazy(() => import('./components/ContractGenerator'));
```

## 💾 Хранение данных

### Калькулятор прайса:
- Данные сохраняются в `data.priceCategories` и `data.globalPriceParams`
- Автоматическое сохранение при каждом изменении
- При загрузке страницы состояние восстанавливается из localStorage

### Генератор договоров:
- Данные формы не сохраняются (сбрасываются при перезагрузке)
- Можно добавить сохранение в sessionStorage при необходимости
