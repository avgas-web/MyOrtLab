## ⚠️ Проблема с белым экраном

Если после деплоя сайт открывается с белым экраном, выполните следующие шаги:

### Шаг 1: Очистите localStorage

Откройте консоль браузера (F12) и выполните:

```javascript
localStorage.clear();
location.reload();
```

Это очистит старые данные и перезагрузит страницу с новыми данными.

### Шаг 2: Проверьте консоль браузера на ошибки

1. Откройте консоль браузера (F12)
2. Перейдите на вкладку **Console**
3. Проверьте наличие ошибок (красные сообщения)
4. Если есть ошибки, скопируйте их и отправьте разработчику

### Шаг 3: Проверьте вкладку Network

1. Откройте вкладку **Network** в DevTools
2. Обновите страницу (F5)
3. Проверьте статусы загрузки файлов:
   - ✅ Все файлы должны загружаться со статусом 200
   - ❌ Если есть файлы со статусом 404 - проблема с путями
   - ❌ Если есть файлы со статусом 500 - проблема с сервером

### Шаг 4: Проверьте версию Node.js в workflow

Предупреждение о Node.js 20 не критично. Оно связано с самими GitHub Actions, а не с нашим кодом.

**Текущая конфигурация:**

- Проект собирается успешно ✅
- Все компоненты работают ✅

### Шаг 5: Проверьте базовый путь

Убедитесь, что в `vite.config.js` правильно настроен базовый путь:

```javascript
const getBasePath = () => {
  if (process.env.GITHUB_REPOSITORY) {
    const repoName = process.env.GITHUB_REPOSITORY.split('/')[1];
    return `/${repoName}/`;
  }
  return './';
};
```

## 🐛 Частые причины белого экрана

### Причина 1: Старые данные в localStorage

**Решение:**
```javascript
localStorage.clear();
location.reload();
```

### Причина 2: Ошибка JavaScript

**Решение:**
1. Откройте консоль браузера (F12)
2. Найдите красные сообщения об ошибках
3. Скопируйте текст ошибки
4. Отправьте разработчику

### Причина 3: Проблема с путями к файлам

**Решение:**
1. Проверьте, что в `vite.config.js` правильно настроен `base`
2. Проверьте, что имя репозитория совпадает с базовым путем
3. Пересоберите проект: `npm run build`

### Причина 4: Проблема с CORS

**Решение:**
1. Убедитесь, что репозиторий публичный
2. Проверьте настройки GitHub Pages
3. Проверьте, что workflow завершился успешно
