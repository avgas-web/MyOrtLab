# Исправление расчёта суммы услуг в заказ-наряде

## Проблема

В заказ-наряде и других местах системы сумма услуг рассчитывалась неправильно. Не учитывалось количество позиций при расчёте общей суммы.

## Корень проблемы

В системе было несколько мест с неправильным расчётом:

### 1. Создание заказа (NewOrderView)

**Было:**
```typescript
positions: positions.map(p => ({
  id: genId(), name: p.name, svcId: p.svcId, cat: p.cat, qty: p.qty, price: p.price * p.qty,
  ops: []
})),
```

**Проблема:** В поле `price` сохранялась уже умноженная на количество сумма.

**Исправлено:**
```typescript
positions: positions.map(p => ({
  id: genId(), name: p.name, svcId: p.svcId, cat: p.cat, qty: p.qty, price: p.price,
  ops: []
})),
```

**Решение:** В поле `price` теперь хранится цена за единицу, а количество хранится в `qty`.

### 2. Заказ-наряд (printOrder)

**Было:**
```typescript
const total = order.positions.reduce((s, p) => s + p.price, 0);
```

**Проблема:** Сумма рассчитывалась без учёта количества.

**Исправлено:**
```typescript
const total = order.positions.reduce((s, p) => {
  const pricePerUnit = p.price || 0;
  const qty = p.qty || 1;
  return s + (pricePerUnit * qty);
}, 0);
```

**Решение:** Теперь правильно умножается цена на количество для каждой позиции.

### 3. Модальное окно заказа (OrderModal)

**Было:**
```typescript
const totalAmount = order.positions.reduce((s: number, p: any) => {
  if (p.price === 0 || p.price === null) {
    const svc = (data.catalog || []).find((c: any) => c.id === p.svcId);
    return s + (svc?.price || 0) * (p.qty || 1);
  }
  return s + (p.price || 0);
}, 0);
```

**Проблема:** В последней строке не умножалось на количество.

**Исправлено:**
```typescript
const totalAmount = order.positions.reduce((s: number, p: any) => {
  const qty = p.qty || 1;
  if (p.price === 0 || p.price === null) {
    const svc = (data.catalog || []).find((c: any) => c.id === p.svcId);
    return s + (svc?.price || 0) * qty;
  }
  return s + (p.price || 0) * qty;
}, 0);
```

**Решение:** Теперь всегда умножается на количество.

### 4. Отображение суммы в модальном окне

**Было:**
```typescript
<span className="font-bold">{pos.price.toLocaleString()} ₽</span>
```

**Проблема:** Показывалась цена за единицу, а не общая сумма.

**Исправлено:**
```typescript
<span className="font-bold">{((pos.price || 0) * (pos.qty || 1)).toLocaleString()} ₽</span>
```

**Решение:** Теперь показывается общая сумма с учётом количества.

### 5. Список заказов (OrdersView)

**Было:**
```typescript
const total = order.positions.reduce((s, p) => s + p.price, 0);
```

**Проблема:** Не учитывалось количество.

**Исправлено:**
```typescript
const total = order.positions.reduce((s, p) => s + (p.price || 0) * (p.qty || 1), 0);
```

**Решение:** Теперь правильно рассчитывается общая сумма.

### 6. Экспорт в CSV

**Было:**
```typescript
const total = o.positions.reduce((s, p) => s + p.price, 0);
```

**Проблема:** Не учитывалось количество.

**Исправлено:**
```typescript
const total = o.positions.reduce((s, p) => s + (p.price || 0) * (p.qty || 1), 0);
```

**Решение:** Теперь правильно рассчитывается общая сумма.

### 7. Формирование счёта

**Было:**
```typescript
${order.positions.map((p: any) => `- ${p.name} × ${p.qty} = ${p.price.toLocaleString()} ₽`).join('\n')}
```

**Проблема:** Показывалась цена за единицу, а не общая сумма.

**Исправлено:**
```typescript
${order.positions.map((p: any) => `- ${p.name} × ${p.qty} = ${((p.price || 0) * (p.qty || 1)).toLocaleString()} ₽`).join('\n')}
```

**Решение:** Теперь показывается общая сумма с учётом количества.

## Пример расчёта

### Пример 1: Одна позиция

**Позиция:**
- Название: Коронка металлокерамическая
- Цена за ед.: 15 000 ₽
- Количество: 2

**Расчёт:**
- Сумма позиции: 15 000 × 2 = 30 000 ₽
- Итого: 30 000 ₽

### Пример 2: Несколько позиций

**Позиции:**
1. Коронка металлокерамическая
   - Цена: 15 000 ₽
   - Количество: 2
   - Сумма: 30 000 ₽

2. Винир керамический
   - Цена: 20 000 ₽
   - Количество: 4
   - Сумма: 80 000 ₽

3. Сплинт релаксационный
   - Цена: 8 000 ₽
   - Количество: 1
   - Сумма: 8 000 ₽

**Итого:** 30 000 + 80 000 + 8 000 = 118 000 ₽
