# 🚀 Быстрый старт деплоя на GitHub Pages

## ✅ Что уже настроено

В проекте уже есть все необходимое для автоматического деплоя:
- ✅ Настроен `base: '/MyOrtLab/'` в vite.config.js
- ✅ Создан GitHub Actions workflow для автоматического деплоя
- ✅ Создан файл `.nojekyll` для корректной работы

## 📋 Пошаговая инструкция

### 1️⃣ Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com)
2. Нажмите **"New repository"**
3. Заполните:
   - **Repository name**: `MyOrtLab` ⚠️ **ВАЖНО: имя должно быть точно таким!**
   - **Description**: любое описание
   - **Public** ✅ (обязательно публичный!)
   - **НЕ ставьте** галочки "Add a README file" и другие
4. Нажмите **"Create repository"**

### 2️⃣ Загрузите код в репозиторий

#### Вариант А: Через веб-интерфейс (просто)

1. В созданном репозитории нажмите **"uploading an existing file"**
2. Перетащите **ВСЕ файлы** из папки проекта в окно загрузки
3. Нажмите **"Commit changes"**

#### Вариант Б: Через Git (правильно)

```bash
# В папке с проектом
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/MyOrtLab.git
git push -u origin main
```

### 3️⃣ Включите GitHub Pages

1. В репозитории нажмите **"Settings"** (Настройки)
2. В левом меню выберите **"Pages"**
3. В разделе **"Build and deployment"**:
   - **Source**: выберите **"GitHub Actions"**
4. Готово! GitHub автоматически запустит деплой

### 4️⃣ Дождитесь завершения деплоя

1. Перейдите на вкладку **"Actions"**
2. Вы увидите запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь зеленой галочки ✓ (обычно 2-3 минуты)

### 5️⃣ Откройте сайт

Ваш сайт будет доступен по адресу:
```
https://ВАШ_ЛОГИН.github.io/MyOrtLab/
```

Например: `https://john123.github.io/MyOrtLab/`

## ⚠️ Частые проблемы и решения

### Проблема: Сайт не открывается (404)

**Решение**: Имя репозитория должно быть точно `MyOrtLab` (с заглавной буквы M и O, L)

### Проблема: Белый экран

**Решение**: 
1. Откройте консоль браузера (F12)
2. Проверьте ошибки
3. Убедитесь, что в Settings → Pages выбрано "GitHub Actions"

### Проблема: Стили не загружаются

**Решение**: 
1. Проверьте, что в `vite.config.js` есть `base: '/MyOrtLab/'`
2. Убедитесь, что имя репозитория совпадает с base path
3. Пересоберите проект: `npm run build`
4. Запушьте изменения

## 🔄 Автоматический деплой

Теперь при каждом `git push` сайт будет автоматически пересобираться и обновляться!

## 📊 Проверка статуса

1. Вкладка **"Actions"** - показывает статус всех деплоев
2. Зеленая галочка ✓ - успешно
3. Красный крест ✗ - ошибка (кликните для просмотра логов)
